# Claude 三条建议：实测核查与修订结果

## 1. 基线不是固定的全排序

fused_flat 在 C++ 中生成和归一化端点，然后调用 selected。
selected 使用 std::nth_element 取得端点计数中位数，再按累计权重决定
继续哪一侧。活跃元素数每次至少减半；分区路径为平均线性时间，
最终的下尾前驱查找另做一次线性扫描。C++ 标准对非并行 nth_element
规定平均线性复杂度，不保证确定性最坏线性时间。
目前编译环境 libstdc++ 11.1 的 introselect 在深度耗尽时使用 heap_select。
我们的歧义路径进一步使用全排序保留离散尾政策。

Table 7 六组原始记录中，native_flat 的排序回退全部为 0/1024；
所以约 3 ms/尾确实来自分区选择路径。Table 2 的 fused_flat 则有
30,50,75,78,99,132 次排序回退；索引回退已计入原表的时间。
不能把基线称作固定全排序，也不能把它称作保证最坏线性的选择算法。

## 2. Housing 回退确实与有放回抽样有关

21 个原缩放状态、每个 512 双尾查询：值二分和秩搜索每个后端
均为 859/21504 次回退，全部是 lower_crossing_tie。
每个触发点的整个并列组均对应同一原始行 ID、同一折。
默认值二分与秩后端的回退数量在所有原表格单元中一致。

12 个无放回状态（三种子 × K=2,5,10,20）：每后端 12288 个尾查询，
均为零回退。对照保持原查询 ID 和建模配方，重新拟合模型；
因此不能只凭对照宣称所有实际校准集都无并列。
归因来自原状态每个触发点的行 ID 记录，而非仅靠对照相关性。

六个主数据状态每后端共 462 个回退，均为下尾并列。其中
SGEMM/RF 有 1 个、Bike/RF 有 26 个触发并列组包含不同原始 ID；
其余组均为同 ID 同折重复。不能把全部 RF 并列归于重复采样。
窄分布还可以因 binary64 数值聚集产生同值端点。

## 3. 查询复杂度、正确性与数值范围

令 L=K+sum_k log(N_k+1)，I 为实际迭代次数。值查询 O(I L)，
秩查询 O(I[L+K log K])；临时查询状态 O(K)。
秩中位数使用活跃长度作权重，至少一半活跃长度的折在 pivot
某一侧，其各自至少一半端点被剪掉，每次非终止迭代淘汰至少
四分之一活跃端点。因此秩路径 I=O(log(N+1))，与数值幅度无关。
值路径没有对应的计数收缩保证；当前实现最多 80 次迭代后回退。
回退增加 O(N) 物化和平均 O(N) 分区选择；排序回退为 O(N log N)。
实测编译库下，包括 introselect 的最坏堆选择路径也为 O(N log N)。
批接口额外承担 O(QK) 查询输入验证与复制，结果存储 O(Q)。

正确性论证使用精确算术：折内共同平移保持排序，正比例质量系数
保留累计质量；每个 pivot 的 before/at CDF 精确表示全体端点分布。
target 低于 before 时只舍弃 pivot 及其右侧，高于 at 时只舍弃
pivot 及其左侧。保持首次 CDF 穿越点的活跃范围不变量，严格位于
单一有限原子的质量区间时可返回上尾穿越点或下尾的全局前驱。
下尾并列和 CDF 等号进入精确离散政策路径，因为同值原子中的
前驱可能仍是该端点本身；字典序排序保留质量和原行顺序。
无限原子同样作为离散 CDF 质量处理。浮点实现采用余量判断及
回退；上述精确算术论证不被表述为普适的逐位浮点正确性定理。

### 不使用 log1p 的预设数值分布

N=16000, K=5, Q=128；V/R 迭代列为 p50/p95/max。
F/V/R 时间为未插桩原公开批接口三次查询时间中位数，不含准备或拟合。
四个分布全部报告，非新的实际应用。宽梯是300个2^1至2^300的
几何梯级，其余残差集中于1附近；值二分逐次剪去少量远端点，
触发80次上限，秩搜索保持计数收缩。

| Residual distribution | V iterations | R iterations | V / R fallbacks | F / V / R (ms) |
|---|---:|---:|---:|---:|
| Raw exponential | 15/16/17 | 14/15/16 | 0 / 0 | 136.49 / 2.49 / 3.58 |

Pareto 使值迭代增加，但本机对应查询时间仍略快于秩；不能从
迭代次数直接推导运行时间。宽梯的秩查询时间明显较低；这支持
保留可选秩后端，默认值二分在原三个 log1p 数据域中的实证优势不变。

## 结果完整性与复现

43 个状态，每后端 40960 个尾查询；共81920个诊断端点。
对照冻结输出或独立物化离散CDF，最大有限端点差异为0，
无限端点差异为0。没有改动生产算法、覆盖旧结果或调整80次上限。
run_v1 下保留每个数值状态、逐查询迭代、原因、并列组行ID和原始计时。
这些补充解决论证与实验覆盖缺口；并不将经典选择算法变成新算法。
